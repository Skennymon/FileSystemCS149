File System Simulator for the Linux Operating System using C as the programming language.





This does not modify the real operating system files; this instead creates an in-memory file system using C structs for files and directories!



By Kenny Nguyen, Indpaul Johl, \& Andy Martin-Valencia





\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~  FEATURES \~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~



* Create files using 'touch' or 'create'
* Create directories using 'mkdir'
* Change directories using 'cd'
* Print the current directory using 'pwd'
* Edit file contents using 'edit'
* Read file contents using 'cat'
* Open and close files using 'open' and 'close'
* Delete files using 'rm' or 'delete'
* Remove directories using 'rmdir'
* List files and directories using 'ls'
* Search for files using 'search'
* Rename files or directories using 'rename'
* Display file information using 'info'
* Show command list using 'help'







\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~  HOW TO COMPILE \~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~



Navigate/CD to directory you'd like to download the project.





Type:

&#x20;'git clone https://github.com/Skennymon/FileSystemCS149.git'



Navigate/CD to the project folder:

&#x20;'cd FileSystemCS149'



Compile: 

&#x20;'gcc -Wall -Wextra -o filesystem FileSystem.c'





\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~  HOW TO RUN \~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~\~



Type: 

./filesystem
